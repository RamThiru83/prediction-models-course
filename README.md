# Prediction Models Course

A self-contained, interactive course on developing and validating clinical prediction models, with maternal and child health examples. Built on the principles of Steyerberg, *Clinical Prediction Models* (Chapters 1-19); the course carries original content and does not reproduce the book's text.

Single-file web app (`index.html`): primer, 15 modules, simulators, quizzes, case tasks with worked answers, an Analysis Lab and downloadable datasets.

All datasets are synthetic and contain no participant data. For teaching use after instructor review.
